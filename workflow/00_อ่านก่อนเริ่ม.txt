================================================================================
  ชุดออโตเมชัน Compile + Backtest + Optimize สำหรับ XAU_StraddleReverse v4.41
================================================================================

ผม (Claude) ไม่มีการเชื่อมต่อเข้าไปรันบน VPS ของคุณได้จริง ชุดนี้คือสคริปต์ที่คุณ
ต้องกดรันเองบน VPS แต่ทำให้ไม่ต้องคลิกทีละหน้าต่างใน GUI ทุกรอบ

--------------------------------------------------------------------------------
สิ่งที่ต้องทำก่อนรันไฟล์ไหนทั้งสิ้น
--------------------------------------------------------------------------------

1. วางไฟล์ .mq5 กับ .set (จากไฟล์ที่ผมส่งให้ก่อนหน้านี้) ลงใน Data Folder ของ MT5
   ให้เรียบร้อยก่อน (File -> Open Data Folder ใน MT5 -> MQL5\Experts\ และ MQL5\Presets\)

2. หา path 3 เส้นนี้จากเครื่องคุณ:

   ก) path ของ metaeditor64.exe
      -> คลิกขวาไอคอน "MetaEditor 5" บน Desktop -> Properties -> ช่อง "Target"
      -> copy ทั้งบรรทัดมา

   ข) path ของ terminal64.exe
      -> คลิกขวาไอคอน "terminal64 - Shortcut" บน Desktop -> Properties -> ช่อง "Target"
      -> copy ทั้งบรรทัดมา

   ค) path ของ Data Folder
      -> ใน MT5: File -> Open Data Folder -> หน้าต่าง Explorer เปิดขึ้นมา
      -> คลิกที่ address bar ด้านบน จะเห็น path เต็ม copy มา

3. เปิดไฟล์ 01_compile.bat, 02_run_backtest_verify.bat, 03_run_optimize.bat
   ด้วย Notepad (คลิกขวา -> Edit หรือ Open with -> Notepad)
   แล้วแทนที่ 2 บรรทัด METAEDITOR_EXE / TERMINAL_EXE / DATA_FOLDER
   ด้วย path จริงของคุณ (ต้องมีเครื่องหมาย " ครอบไว้เหมือนเดิม)

4. รันตามลำดับ: 01 -> 02 -> 03 (ห้ามข้าม 02 ไปตรง 03 เด็ดขาด)

--------------------------------------------------------------------------------
ลำดับการรัน
--------------------------------------------------------------------------------

01_compile.bat
  คอมไพล์ไฟล์ .mq5 เป็น .ex5 ผ่าน command line
  เช็คผลใน compile_log.txt ที่มันสร้างไว้ ต้องเห็นคำว่า "0 error(s)"
  ถ้าไม่ผ่าน ห้ามไปขั้นต่อ ส่ง compile_log.txt มาให้ผมดู

02_run_backtest_verify.bat (ใช้คู่กับ 02_backtest_verify.ini)
  รัน Backtest 1 รอบด้วยค่าจาก SET_StraddleReverse_QUALITY_v2 (ฝังไว้ใน .ini แล้ว)
  โหมด "1 Minute OHLC" ตามที่กำหนดไว้ในไฟล์ (Model=1)
  *** ก่อนไปขั้น 03 ให้เปิดไฟล์รายงาน .htm ที่ได้ เทียบกับที่คุณเคยรันผ่าน GUI มาก่อน
      ตัวเลขกำไร/PF/จำนวนไม้ ต้องใกล้เคียงกัน ถ้าต่างกันมาก แปลว่า .iniตั้งค่าไม่ตรงกับที่ตั้งใจ
      (เช่น Model index หรือ FromDate/ToDate ไม่ตรง) หยุดแล้วบอกผมก่อนรัน 03

03_run_optimize.bat (ใช้คู่กับ 03_optimize.ini)
  รัน Optimization แบบ Slow complete algorithm ตามช่วงพารามิเตอร์ที่แนะนำไว้
  ใช้เวลานาน (หลายชั่วโมงถึงเป็นวัน ขึ้นกับจำนวน combination) รันทิ้งไว้ข้ามคืนได้
  เสร็จแล้วเทอร์มินัลจะปิดตัวเองอัตโนมัติ (ShutdownTerminal=1)

--------------------------------------------------------------------------------
สิ่งที่ต้องแก้เองก่อนรันจริง (อย่าลืม!)
--------------------------------------------------------------------------------

- ไฟล์ .ini ทั้งสอง ต้องเซฟด้วย encoding "UTF-16 LE" (Unicode) ไม่ใช่ UTF-8/ANSI
  ไม่งั้น MT5 อ่านไฟล์ไม่ออกแล้วรันด้วยค่า default ทั้งหมดเงียบๆ โดยไม่มี error ชัดเจน
  วิธีเช็ค/แก้ใน Notepad (Windows 11): File -> Save As -> ช่อง Encoding เลือก "UTF-16 LE"
  ผมเซฟไฟล์ที่แนบมาเป็น UTF-16 LE ไว้แล้ว แต่ถ้าคุณเปิดแล้วแก้ค่าใน Notepad แล้ว save
  ทับ ให้เช็ค encoding ซ้ำทุกครั้งก่อนรัน

- FromDate / ToDate ใน 02_backtest_verify.ini และ 03_optimize.ini ตอนนี้ใส่เป็น
  2026.06.01 - 2026.08.01 ไว้ชั่วคราว แก้ให้ตรงกับช่วงข้อมูล M1 ที่คุณโหลดจริงบน VPS

- ค่า Model=1 (1 Minute OHLC), OptimizationCriterion=1 (Profit Factor max) ที่ตั้งไว้
  อ้างอิงจากเอกสาร MQL5 มาตรฐาน แต่ index อาจขยับได้ตามเวอร์ชัน MT5 -- ขั้นตอน 02 ที่ให้
  เทียบกับ GUI ก่อน คือตัวเช็คว่า index พวกนี้ตรงกับเครื่องคุณจริงไหม

- [Common] Login / Password / Server ในไฟล์ .ini ปล่อยว่างไว้ ใส่เองบนเครื่องคุณเท่านั้น
  ห้ามส่งไฟล์ที่กรอกรหัสผ่านแล้วกลับมาให้ผมเด็ดขาด

--------------------------------------------------------------------------------
พอรันขั้น 03 เสร็จแล้ว ส่งอะไรกลับมาให้ผมดูต่อ
--------------------------------------------------------------------------------

ตำแหน่งขยับได้ตามบิลด์ ลองหาไฟล์ที่ชื่อขึ้นต้นด้วย SRv441 ทั้งหมด):
  - SRv441_verify.htm (ผลยืนยันขั้น 02)

ส่งไฟล์พวกนี้กลับมา ผมจะช่วยกรอง overfit / เลือกชุดพารามิเตอร์ที่น่าเชื่อถือ /
